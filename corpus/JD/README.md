# JD 语料库（招聘职位描述）

本目录存放从国家大学生就业服务平台（ncss.cn，教育部官方）抓取的正式岗位 JD 数据集。
数据来源全部为平台公开的职位列表接口与详情页，未涉及登录态。

## 子目录

| 目录 | 方向 | 份数 | 内容 |
|---|---|---|---|
| `agent_dev/` | Agent / 大模型应用开发岗（含相邻岗位） | 72 | 每份 JD 一个 md + `unified.csv` + `README.md` |
| `marketing/` | 运营 / 市场营销岗（已剔除保险、推销类） | 413 | 每份 JD 一个 md + CSV + `README.md` + `SUMMARY.md` |

## 每份 JD 的 md 结构

- 职位原文（详情页 `<pre class="mainContent">` 原文，未改写）
- 结构化字段：职位名称、招聘类型、薪资、学历、招聘人数、专业、地区、更新时间、信息来源
- 公司信息：招聘主体、所属行业、公司性质、公司规模、公司网址、所在地址
- 福利标签、技术关键词 / 岗位特征
- 同模板的其他投放（同一 JD 正文被不同分公司重复投放的去重记录）

## 去重口径

1. 取详情页 `<pre class="mainContent">` 的完整正文；
2. 去掉所有空白和标点后取 SHA1 前 12 位作为指纹；
3. 指纹相同的归为一组，只保留相关度最高的一条作为代表，其余在该文件的「同模板的其他投放」里列出；
4. `agent_dev` 为三批抓取（2026-07-31 严格版 / 2026-08-04 严格版 / 2026-08-04 宽松版）按指纹合并去重后的全集。

## 采集工具

- 抓取：`scripts/fetch_ncss_jobs.py`（支持 `--direction agent|marketing`、`--loose`）
- 合并：`scripts/merge_ncss_job_batches.py`
- 统计：`scripts/analyze_ncss_marketing.py`
- 原始输出与历史批次保留在 `exports/`

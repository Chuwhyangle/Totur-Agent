```text
一、岗位简介

本岗位面向企业内部业务场景，负责把业务需求转化为可落地的智能体（AI Agent）应用。你将与业务团队紧密协作，理解业务诉求，把抽象需求拆解为可执行的数据管道设计与工作流程，并借助低代码 / Agent 平台搭建出真正可用的智能体应用。岗位定位为初级程序员，但对需求理解与拆解能力要求较高，适合逻辑清晰、善于沟通、对 AI 应用有热情的同学



二、岗位职责

1、对接业务团队，理解并抽象业务需求，将模糊、抽象的诉求转化为清晰的智能体应用目标。

2、把业务需求拆解为可执行的数据管道（Data Pipeline）设计与工作流程（Workflow），明确每一步的输入、处理与输出。

3、基于智能体 / 工作流平台搭建、配置并调试智能体应用。

4、设计并编写提示词（Prompt），对接知识库、数据库与外部工具 / API，打通端到端流程。

5、对智能体应用进行测试、评估与迭代优化，持续提升准确率、稳定性与用户体验。

6、与数据团队协作，提出数据准备与对接需求，保障应用所需数据的质量与可用性。

7、淀需求文档、流程设计与应用说明，支持业务方使用与推广。



三、任职要求（硬性）

1、本科及以上学历，计算机、电子信息、软件工程、人工智能等相关专业。

2、具备较强的需求理解与逻辑拆解能力，能把抽象业务问题拆解为清晰的流程与步骤。

3、了解数据管道 / 工作流的基本概念，能设计合理的数据流转与处理流程。

4、具备基础编程能力，能读懂并编写脚本（如 Python / JavaScript），理解 API 调用与数据交互。

5、具备 Vibe Coding 能力：能熟练借助 AI 编程工具（如 Cursor、Claude、Copilot 等）快速搭建与调试应用。

6、沟通表达能力强，善于与业务方协作，主动、皮实、学习能力强。





四、加分项

1、有智能体 / 工作流平台（Coze、Dify、n8n、LangChain 等）的搭建或实践经验。

2、了解大模型（LLM）、RAG、Prompt 工程等相关概念。

3、有数据库 / SQL 基础，能独立完成简单的数据查询与处理。

4、有面向业务的项目经验，能从 0 到 1 推动一个应用 / 工具落地。





五、培养政策

1、处于 AI 应用落地一线，深度参与企业级智能体从设计到上线全过程。

2、导师带教 + 系统培养，快速成长为复合型 AI 应用人才。
```

## 与 Tutor Agent 项目的对应点

- **Python** → 整个后端都是 Python，含类型标注、pytest 自动化测试和本地脚本工具链。
- **JavaScript/TypeScript** → `frontend/` 的 React + Vite 工作台，含会话列表、人设下拉和工具调用轨迹展示。
- **大模型/LLM** → OpenAI-compatible 客户端接入，chat 与 embedding 走两套独立配置（`OPENAI_BASE_URL` / `EMBEDDING_BASE_URL`），密钥走环境变量不入库。
- **Agent** → `app/services/agent/` 里的 ReAct 多轮工具循环：模型可连续多轮请求工具，`tool_trace.calls[]` 记录工具名、参数、结果摘要和 round。
- **RAG** → `scripts/build_knowledge_index.py` 扫描 `docs/**/*.md` 建 Chroma `learning_notes` 索引，`search_learning_notes` 检索后强制回答标注来源。
- **Prompt** → prompt 模块 + 可切换导师人设（`GET /personas`），以及结构化回复的解析与容错。
- **数据库** → SQLite 表设计与 `repositories/` 读写分层，持久化对话、会话、摘要和面试 JD。

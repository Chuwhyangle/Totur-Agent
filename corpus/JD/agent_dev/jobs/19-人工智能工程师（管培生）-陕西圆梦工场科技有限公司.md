```text
人工智能工程师（管培生）岗位职责

岗位定位：人工智能工程师（管培生）为校招储备培养型岗位，在资深工程师与导师带教下，系统学习AI算法研发、数据处理、模型训练、工程部署与业务落地全流程工作。以学习成长、实操落地、轮岗沉淀为核心，辅助团队完成AI项目研发与迭代，逐步具备独立负责基础AI模块的能力，最终成长为全能型人工智能技术骨干。

一、技术研发学习与辅助职责

1. 在导师指导下，系统学习机器学习、深度学习、大模型、多模态（CV/NLP）等AI核心技术，跟进行业前沿技术动态，完成技术复盘与知识沉淀。

2. 协助团队开展大模型微调、Prompt工程、LoRA微调、模型量化、蒸馏优化等基础实操工作，辅助完成模型效果测试、参数记录与数据对比。

3. 参与AI算法复现、模型适配、场景调试等基础研发工作，协助攻克基础技术难点，配合完成项目技术迭代与创新落地。

4. 参与技术调研、竞品AI方案分析、前沿算法研读，输出技术学习报告与调研总结，为团队技术升级提供参考。

二、数据处理与数据集建设职责

1. 协助完成业务数据的采集、筛选、清洗、去噪、预处理工作，配合搭建规范的模型训练数据集、测试数据集，保障训练数据基础质量。

2. 严格按照团队标准，协助制定数据标注规范，跟进数据标注流程，核验标注质量，整改标注误差，解决样本稀疏、数据不均衡等基础问题。

3. 协助维护数据集迭代机制，整理线上业务增量数据，更新训练样本库，支撑模型持续迭代优化。

三、模型训练、测试与优化辅助职责

1. 协助资深工程师搭建模型训练、验证、评估基础管线，参与模型超参数调试、实验训练、效果复盘、数据统计工作。

2. 配合完成模型多维度评测，统计准确率、召回率、推理速度、稳定性等核心指标，整理评测数据，输出基础评测报告。

3. 协助排查模型过拟合、幻觉、精度波动、场景适配不足等基础问题，配合完成模型轻量化、稳定性优化工作。

四、工程落地与运维辅助职责

1. 学习AI模型工程化落地流程，协助完成模型封装、接口调试、服务部署、环境适配等基础工作。

2. 协助开展模型推理加速、资源优化、适配调试工作，配合完成服务器、终端、边缘设备的基础适配落地。

3. 参与线上AI服务日常监控、日志查看、基础故障排查与运维登记，记录运行问题，配合完成系统优化，保障服务稳定运行。

五、业务对接与项目落地职责

1. 配合产品、业务团队理解业务需求，协助完成需求拆解、问题梳理、方案整理，辅助输出基础技术落地文档。

2. 参与AI赋能项目的需求评审、技术研讨、进度跟进，协助完成智能化功能迭代、场景落地、效果验收工作。

3. 跟踪线上AI功能使用反馈、业务数据，整理迭代建议，配合团队完成产品与模型优化升级。

六、文档沉淀与规范执行职责

1. 严格遵守团队开发规范、代码管理、实验管理标准，养成标准化研发习惯，保障项目可维护、可迭代。

2. 负责整理、撰写学习笔记、实验日志、技术文档、部署手册、迭代台账、测试报告等基础资料，沉淀个人与团队技术成果。

3. 积极参与团队技术分享、复盘研讨、技术攻坚，快速补齐技术短板，同步提升理论与实操能力。

七、合规风控与岗位成长职责

1. 严格遵守数据安全、隐私保护、AI伦理、内容合规相关规定，杜绝数据泄露、模型滥用、内容违规等风险问题。

2. 协助完成AI输出内容风险排查、基础风控校验，养成合规化研发、规范化操作的职业习惯。

3. 按照管培生培养计划完成阶段性轮岗、学习考核、实操任务，定期复盘成长进度，达成岗位培养目标。

管培生核心能力要求（应届生适配版）

1. 本科及以上学历，人工智能、计算机科学与技术、大数据、软件工程、自动化等相关专业，基础扎实；

2. 熟练掌握Python基础语法，了解PyTorch、TensorFlow等主流深度学习框架基本用法；

3. 掌握机器学习、深度学习、数据处理、模型训练基础理论，有相关课程项目、实训项目经验优先；

4. 具备良好的逻辑思维、学习能力、执行力和团队协作能力，愿意深耕AI技术，能接受阶段性轮岗培养；

5. 工作严谨细致、责任心强，具备较强的问题排查能力与持续学习意识，适配技术落地实操工作。

管培生培养方向与定岗目标

1. 培养周期：6–12个月系统化带教+轮岗实操，阶段性考核通关；

2. 成长路径：零基础实操学习→模块辅助开发→独立负责基础模块→全流程AI技术工程师；

3. 定岗方向：AI算法研发工程师、大模型应用工程师、AI数据算法工程师、AI工程部署运维工程师。
```

## 与 Tutor Agent 项目的对应点

- **Python** → 整个后端都是 Python，含类型标注、pytest 自动化测试和本地脚本工具链。
- **大模型/LLM** → OpenAI-compatible 客户端接入，chat 与 embedding 走两套独立配置（`OPENAI_BASE_URL` / `EMBEDDING_BASE_URL`），密钥走环境变量不入库。
- **Prompt** → prompt 模块 + 可切换导师人设（`GET /personas`），以及结构化回复的解析与容错。
- **模型训练/微调** → 项目没做训练，别硬写；可以讲检索/生成侧的离线评测脚本（`run_retrieval_eval.py`、`run_generation_eval.py`）来对齐「效果度量」这件事。
- **推理部署** → 项目走的是 API 接入而非自建推理，面试时讲清楚取舍即可，不要伪装部署经验。
- **爬虫/数据处理** → 本次 NCSS 职位抓取脚本本身就是样例：公开接口分页、详情页解析、正文哈希去重、结构化落盘。
